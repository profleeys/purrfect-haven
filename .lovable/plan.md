## 目標
把「線上預約」表單從純前端狀態改為真正寫入資料庫。

## 後端（Lovable Cloud）
啟用 Lovable Cloud（內建資料庫，不需另外註冊帳號），並建立 `reservations` 資料表：

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| id | uuid | 主鍵，自動產生 |
| name | text | 姓名 |
| phone | text | 聯絡電話 |
| visit_date | date | 來店日期 |
| time_slot | text | 時段 |
| party_size | int | 人數（1–8） |
| note | text | 備註，可空 |
| status | text | 預約狀態，預設 `pending` |
| created_at | timestamptz | 建立時間 |

安全設定：
- 開啟 RLS。
- 允許任何訪客「新增」預約（公開表單需要），但**不開放任何讀取**，避免其他人看到客人的姓名與電話。
- 後台讀取留給日後的管理員角色（本次不做登入後台）。

## 前端
1. 預約表單改為受控欄位，送出時寫入資料庫。
2. 送出中顯示 loading、按鈕禁用，避免重複送出。
3. 成功後顯示現有的成功訊息並清空表單；失敗顯示錯誤提示（使用 sonner toast）。
4. 基本驗證：電話格式、日期不可早於今天、人數 1–8。
